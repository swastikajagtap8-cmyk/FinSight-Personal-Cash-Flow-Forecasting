      How FinSight works

      Dataset layer

      Seeded 75-day transaction ledger with a normalised schema: id, date, category, description, amount.

      Categorisation

      Keyword-based classifier maps each description to Groceries, Tech, Leisure or Bills.

      Forecast engine

      Trailing-average projection with a trend term and a seasonal festival uplift.

      Recommendation engine

      Turns total overspend into a capped, category-weighted recovery schedule.
